J&T ROUTE v0.3 — SELECTOR DE ESTILOS DE REPORTE

Incluye un menú lateral derecho con 6 formatos de mensaje:
1. ZERO SYSTEM — Minimalismo cyber (predeterminado)
2. NEON TOKYO — Anime futurista
3. GHOST PROTOCOL — Terminal táctico
4. ORBITAL DELIVERY — Ciencia ficción
5. CYBER COMMAND — Centro de operaciones
6. MATRIX DELIVERY — Hacker terminal

Cómo instalar:
1. Descomprime el ZIP.
2. En GitHub abre el repositorio pexa0n2k-hub/JTrout.
3. Reemplaza index.html, style.css y app.js por los de esta carpeta.
4. Haz Commit changes en la rama main.
5. Abre GitHub Pages y recarga la PWA. Si Android muestra la versión anterior, cierra la pestaña y vuelve a abrirla.

El estilo elegido se guarda en el dispositivo y cambia únicamente el texto del reporte. No altera la captura, los datos de ruta ni el diseño principal.
