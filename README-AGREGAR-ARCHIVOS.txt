J&T ROUTE - ARCHIVOS FALTANTES

Sube estos archivos a la RAIZ del repositorio JTrout, conservando tu index.html actual:
- style.css
- app.js
- manifest.webmanifest
- sw.js
- .github/workflows/pages.yml

IMPORTANTE:
1. En GitHub, usa Add file > Upload files.
2. Para el workflow, asegúrate de conservar la carpeta .github/workflows.
3. Haz commit a la rama main.
4. En Settings > Pages, selecciona Source: GitHub Actions.
5. Abre Actions y espera a que termine Publish J&T Route PWA.
6. Recarga https://pexa0n2k-hub.github.io/JTrout/

Los reportes y el historial se guardan localmente en el navegador.
La opción Compartir usa Web Share API cuando el navegador admite compartir archivos.
